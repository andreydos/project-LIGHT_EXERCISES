## Про проєкт

**LIGHT EXERCISES** — вебпроєкт для ознайомлення з фізичними вправами та виконання тренувань. Кожна вправа представлена окремою сторінкою з відповідною інформацією, що дозволяє користувачам легко знаходити потрібні вправи та формувати власну активність.

Проєкт реалізований з адаптивним дизайном для комфортного використання на різних пристроях: комп'ютерах, планшетах і мобільних телефонах.

## Функціональність

- Адаптивний дизайн для мобільних пристроїв, планшетів і десктопів
- Каталог фізичних вправ, розподілених за групами м'язів (ABS, Delts, Legs тощо)
- Перегляд списку вправ у межах обраної категорії
- Відображення інформації про кожну вправу: назва, тривалість виконання та кількість спалених калорій
- Детальна інформація про вправу із зображенням-схемою та візуальним виділенням задіяних груп м'язів
- Можливість додавати вправи до списку улюблених
- Перегляд обраних улюблених вправ
- Посилання на соціальні мережі
- Можливість підписатися на розсилку

## Встановлення та запуск

```bash
npm install - Встанови базові залежності проекту в терміналі командою
npm run dev - Запусти режим розробки, виконавши в терміналі команду
```

Після запуску перейдіть у браузері за адресою, що вказана в терміналі. 
Типова адреса:

```text
http://localhost:5173
```

Ця сторінка буде автоматично перезавантажуватись після збереження змін у файли проекту.

## Робочий процес

1. Завдання створюються та відстежуються в GitHub Projects.
2. Кожен учасник команди працює над своїми завданнями в окремій гілці.
3. Зміни фіксуються за допомогою комітів із зрозумілими та інформативними повідомленнями.
4. Для внесення змін у гілку main створюється Pull Request.
5. Перед злиттям код проходить перевірку (Code Review).
6. Пряме внесення змін у гілку main не допускається.
7. Після злиття змін у main автоматично запускається процес деплою.
